## Data downloaded at runtime

These databases are not part of the binary or the release packages. i-Tracker
downloads one of them on first start and keeps it up to date; the map shows the
attribution of the source in use.

- **DB-IP City Lite** (default, no account needed): IP Geolocation by DB-IP,
  https://db-ip.com, licensed under the Creative Commons Attribution 4.0
  International License (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/.
  Downloaded unmodified from https://download.db-ip.com/free/.
- **MaxMind GeoLite2 City** (only with the operator's own MaxMind account and license
  key): This product includes GeoLite2 data created by MaxMind, available from
  https://www.maxmind.com. Use is governed by the GeoLite2 End User License
  Agreement, which the operator accepts with the MaxMind account.
- **Map tiles** (optional, only when `map.tile_url` is set): the tile server and its
  license are chosen by the operator; set `map.tile_attribution` accordingly. The
  default attribution names the OpenStreetMap contributors (ODbL).
